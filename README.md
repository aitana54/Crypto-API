# Crypto Portfolio API
Esta aplicación es una API REST desarrollada con Node.js, Express y MongoDB que permite gestionar un portfolio de criptomonedas.

La API permite:

- Gestionar usuarios

- Registrar activos (assets) de criptomonedas

- Registrar transacciones de compra y venta

- Consultar el portfolio agregado de un usuario

- Obtener precios actualizados desde la API externa CoinCap

El sistema calcula automáticamente el valor actual del portfolio utilizando el precio actual de los activos.

Además, se ha implementado autenticación mediante JWT, por lo que algunas rutas están protegidas y solo pueden ser utilizadas por usuarios autenticados.
